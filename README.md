## Mitt Webbprojekt
"Erik's Cykel och Mek" är en webbplats som riktar sig till cyklister med olika behov och intressen. På webbplatsen finns information om serviceerbjudanden, försäljning av begagnade cyklar samt kontakt- och besöksuppgifter.

## Funktioner
- Responsiv design
- Dynamisk navigation med JavaScript
- Enkel kontaktformulär
- layout med CSS Flexbox, Grid.

## Kom igång
Så här kan du köra projektet lokalt:
1. Klona repo: git clone https://github.com/sussanvivanco-gif/Projektuppgift.git
  
2. Öppna mappen i din editor:   cd Projektuppgift
   
3. Öppna `index.html` i din webbläsare.

## Tekniker
Projektet är byggt med:
- HTML
- CSS
- JavaScript
